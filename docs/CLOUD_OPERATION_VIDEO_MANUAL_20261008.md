# Cloud制作 ステップ別動画マニュアル（2026-10-08）

## 目的

初めて利用する購入者が「何ができるのか」「次にどこを押すのか」を迷わないように、漫画制作の最初から販売後の確認までを、実画面に沿った匿名化表示で案内する。長い1本の動画ではなく、目的ごとに8本へ分け、必要な工程だけを開いて見返せるようにする。

## 利用者向け構成

1. 市場分析 — 条件を選び、分析結果を保存する
2. AI企画提案 — 3案を比較し、制作する企画を採用する
3. シナリオ作成 — 人物・構成・シーンを確認して初稿を採用する
4. ネーム作成 — ページ・コマ・構図・セリフを確認する
5. 原稿編集 — 人物・画風・参照画像を固定し、画像・文字を整えてPDFを完成させる
6. 作品管理 — 制作状態を確認し、編集再開または販売準備へ進む
7. 販売準備 — 販売下書き、作品公開、販売開始を順番に行う
8. 収益管理 — 注文区分、金額、支払い・返金状態を確認する

ステップ1だけを最初から開き、ステップ2以降は折りたたんで表示する。各ステップには、短い動画、3項目の文字版手順、個別ダウンロードを備える。

## 動画仕様

- 1〜4・6〜8: 各約25秒
- 5「原稿編集」: 約1分
- 1280×720、H.264、15fps、ブラウザ配信用faststart
- 音声なし、日本語字幕付き
- ブラウザ標準の再生・停止・シーク・字幕操作
- 実装中の画面構成、見出し、ボタン文言に沿った匿名化表示

## 配信ファイル

各IDに`.mp4`、`-poster.webp`、`.vtt`の3ファイルを配置する。

- `01-market-analysis-guide`
- `02-proposal-guide`
- `03-scenario-guide`
- `04-storyboard-guide`
- `cloud-creator-operation-guide`
- `06-work-management-guide`
- `07-sales-preparation-guide`
- `08-sales-management-guide`

配置先は`public/manual/cloud/`。動画の再生成は、ffmpeg実行ファイルを`MANGAI_FFMPEG_PATH`へ指定して`npm run manual:cloud:video`を実行する。生成元はrepository内の匿名化済み画面素材とUI定義だけで、Productionや外部サービスからデータを取得しない。

## プライバシーと変更範囲

- 利用者名、メール、実作品、Prompt、APIキー、credit残数などの実データは含めない。
- Production、DB、migration、API、Provider、credit、商品、公開・販売状態は変更しない。
- 実画面の構成・文言へ合わせる一方、表示件数や金額は説明用に匿名化する。
- UI変更時は同じ生成コマンドで該当ステップを更新できる。

## 検証

- 8本すべてにMP4、WebP poster、日本語VTTがあること
- 動画・字幕へ個人情報や秘密値が含まれないこと
- ステップ1が初期表示され、2〜8は目的別に個別展開できること
- 作品一覧・作品画面から動画マニュアルへ移動できること
- lint、型検査、関連テスト、全テスト、Production build、diff checkを実行すること
