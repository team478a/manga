# MANGA Checkpoint Diff Preview v1

## 目的

固定版を復元する前に、現在の作品から何が変わるかを利用者が判断できるようにします。技術的なmanifestやハッシュを見せず、漫画制作上の件数だけを表示します。

## 表示項目

- 固定版の内容へ戻すページ数
- 復元後に現在の作品から外れるページ数
- 章・話・シーン構成の変更件数
- 素材構成の変更件数
- 作品名、説明、綴じ方向、ページ寸法、DPIの変更有無

## 判定方法

- ページはIDとrevisionを比較する
- 章、話、シーン、素材はID集合の差を数える
- 同じ入力から常に同じ結果を返す決定的なhelperを利用する
- 不正または旧形式のmanifestは推測せず「差分を取得できません」と表示する
- 差分を取得できなくても、復元前の自動バックアップとDB側安全検査は維持する

## 情報境界

次の情報は利用者画面へ表示しません。

- checkpoint manifest本体
- Canvas SHA-256、manifest SHA-256
- Canvas JSON
- Storage path
- Provider、モデル、APIキー、単価

## DB・外部環境

- 新規migrationなし
- 新規環境変数なし
- 外部Provider呼び出しなし
- PR #117のcheckpoint／復元テーブルを読み取るだけで、DB契約は変更しない
