# MANGAI 修正領域おすすめ v1

更新日: 2026-08-01

## 目的

部分修正のたびに利用者が白いマスクを最初から描く負担を減らす。選択済みの修正内容から安全な初期範囲を自動配置し、利用者が画像を見ながら塗り足し・消去して確定できるようにする。

## 利用手順

1. 画像が配置されたコマを選択する。
2. 「直したいところ」で顔、手・指、表情、衣装、背景、仕上げを選ぶ。
3. 「直す範囲を塗って部分修正」を開く。
4. 選択内容に合うおすすめ範囲が白く配置される。
5. 必要なら別候補を選び、「塗る」「消す」で範囲を調整する。
6. 修正候補を生成し、修正前後を比較して採用する。

## 提案内容

- 顔: 画面中央上部の顔まわり
- 表情: 顔の内側
- 手・指: 両手、左側の手、右側の手
- 衣装: 中央の上半身
- 背景: 中央の人物を避けた外周
- 全体仕上げ: 画像全体

すべての座標は画像サイズに依存しない正規化値で保持し、縦長・横長画像でも同じ比率で描画する。

## 正確性の境界

v1は画像認識や人物検出を行わず、修正内容に応じた安全な初期領域テンプレートを提示する。実際の顔・手・人物位置を検出したとは表示しない。利用者は元画像上の白い範囲を確認し、必要に応じて手動調整してから生成する。

この方式により、外部Vision APIへの画像送信、追加料金、秘密情報、モデル依存を増やさず、既存のInpainting処理と同じ安全境界を維持する。

## 安全性と変更境界

- 一般向けCloudの表示・クライアント側マスク作成だけを変更する。
- 元画像、作成マスク、生成候補は既存のprivate Asset経路を利用する。
- 手動マスク、サーバー側所有権・形式・寸法検証、BFL Fill、非破壊採用を変更しない。
- DB migration、Feature Flag、環境変数、Provider、料金、成人向け、Desktop、Stripe、Marketplaceは変更しない。

## 受入れ条件

- ダイアログを開くと選択済み修正内容の先頭候補が配置される。
- 手・指では両手、左側、右側を選び直せる。
- 提案を選び直すと古い提案が残らない。
- 提案後もブラシ、消しゴム、太さ変更、全消去を利用できる。
- 手動編集後は提案選択中の表示を解除する。
- 最終PNGは従来どおり黒が保持範囲、白が修正範囲になる。
- スマートフォン幅で候補ボタンが折り返され、横overflowしない。

## 将来拡張

任意の後続機能として、端末内または明示同意済みProviderによる人物・顔・手の実画像検出を追加できる。その場合も検出信頼度を表示し、現在の手動調整とサーバー検証を残す。
