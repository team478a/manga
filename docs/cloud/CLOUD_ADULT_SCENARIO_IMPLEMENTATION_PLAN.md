# Cloud成人向けAIシナリオ 実装計画

## 目的

一般向けシナリオ生成を維持したまま、許可された成人利用者だけに成人向けAIシナリオを提供する。

## 区分

- 一般向け: `content_class=general`。既存の企画→シナリオ→ネーム導線を維持する。
- 成人向け: `content_class=adult`。成人向け市場分析→成人向けAI企画→シナリオ初稿・修正・履歴・採用まで。
- 成人向けネーム、Canvas、画像生成、公開、販売は対象外。
- OpenAI接続は管理画面とSupabase Vaultの既存設定を再利用する。APIキーをローカル、Vercel環境変数、通常テーブル、画面、ログへ複製しない。

## 利用条件

1. 一般向け市場分析・企画・シナリオのFeature Flagが有効
2. 成人向け市場分析と成人向けAI企画を利用可能
3. `CLOUD_ADULT_SCENARIO_GENERATION_ENABLED=true`
4. 成人向けAIシナリオのDB Kill Switchが有効
5. `adult_scenario`の個別許可が有効
6. 成人向けAIシナリオ専用条件へ本人が同意
7. Provider呼出前と結果保存前の安全検査に合格

## 安全境界

- 架空かつ18歳以上と明示された成人だけを扱う。
- 未成年、年齢不詳、実在人物、非同意、搾取的内容を拒否する。
- 入力データ内の命令を無視し、採用企画と市場分析の区分を変えない。
- 根拠のない市場数値、売上保証、参考作品の模倣を生成しない。
- 成人向けシナリオから一般向けネームテーブルへ直接保存できないようRLSでも拒否する。

## 完了条件

- 一般／成人がDB・Server・UIで一貫して区別される。
- 成人向け初稿、修正版、履歴、詳細、採用が完走する。
- 権限失効後はRLSで成人向けシナリオと採用履歴を読めない。
- 成人向けネーム・Canvas・画像生成への導線と直接DB保存が停止する。
- forward、rollback、canonical schema、preflight、テスト、運用文書が揃う。
