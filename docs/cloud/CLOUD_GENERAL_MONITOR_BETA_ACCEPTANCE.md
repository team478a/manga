# 一般向け限定モニター 受入条件

- [ ] Previewへ新規migrationを適用できる
- [ ] 管理者がユーザーを期限・AI上限付きで招待できる
- [ ] 未招待、停止、期限切れ、上限到達時はAIを実行できない
- [ ] 一般向け市場分析からコマ画像生成まで進められる
- [ ] 成人向け入力は拒否される
- [ ] Stripe、販売、Marketplaceを操作しない
- [ ] 本人だけが自分の状態とフィードバックを参照できる
- [ ] 管理者が利用数とフィードバックを確認できる
- [ ] 初回案内の確認日時を保存できる
- [ ] 期限3日前、AI残り5回以下、停止・期限切れ・上限到達が画面に表示される
- [ ] 招待登録と同時に登録済みメールアドレスへ案内が送信される
- [ ] 有効な招待メールを管理者が再送できる
- [ ] 管理者がResend APIキーと送信元を画面から保存・差し替えできる
- [ ] 保存済みAPIキー本体・末尾文字が画面・通常テーブル・監査ログへ再表示されない
- [ ] 送信失敗時に招待登録の成否を誤認しない
- [ ] フィードバックを未対応・対応中・対応済みに更新できる
- [ ] モニター状況をCSV出力できる
- [ ] 390px、768px、1280pxで横スクロールが発生しない
- [ ] preflightと全品質ゲートが成功する
- [ ] スタッフを含む約10名のテストアカウントで招待・停止を確認する
- [ ] 利用者向けWebマニュアルから市場分析とフィードバックへ進める
- [ ] スタッフ向けWebマニュアルから招待・メール設定・CSV出力へ進める
- [ ] 管理画面のテスト公開チェックが秘密値を表示せず全項目「準備完了」になる
- [ ] スタッフ1名、2〜3名、残りの順で段階公開し、各段階の正常動作を確認する

本番公開、課金、成人向け公開は別承認とする。
