# 一般向け限定モニター 受入条件

- [ ] Previewへ新規migrationを適用できる
- [ ] 管理者がユーザーを期限・AI上限付きで招待できる
- [ ] 未招待、停止、期限切れ、上限到達時はAIを実行できない
- [ ] 一般向け市場分析からコマ画像生成まで進められる
- [ ] 成人向け入力は拒否される
- [ ] Stripe、販売、Marketplaceを操作しない
- [ ] 本人だけが自分の状態とフィードバックを参照できる
- [ ] 管理者が利用数とフィードバックを確認できる
- [ ] 初回案内の確認日時を保存できる
- [ ] 期限3日前、AI残り5回以下、停止・期限切れ・上限到達が画面に表示される
- [ ] 管理者が招待メール文面を開ける
- [ ] フィードバックを未対応・対応中・対応済みに更新できる
- [ ] モニター状況をCSV出力できる
- [ ] 390px、768px、1280pxで横スクロールが発生しない
- [ ] preflightと全品質ゲートが成功する
- [ ] 1〜3名のテストアカウントで招待・停止を確認する

本番公開、課金、成人向け公開は別承認とする。
