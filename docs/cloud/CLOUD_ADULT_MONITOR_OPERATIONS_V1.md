# Cloud Adult Monitor Operations v1

## 目的

成人向けCloud機能を、18歳以上かつ管理者が個別許可した限定ユーザーへ
安全に段階公開するための運用機能を追加する。

## 提供範囲

- 市場分析
- AI企画提案
- シナリオ生成
- ネーム生成
- Canvas下書きへの変換
- 非公開作品管理

成人向け画像生成、作品公開、販売、外部共有は対象外。

## 管理者フロー

1. `/admin/adult-monitors/readiness`をすべて準備完了にする。
2. `/admin/adult-monitors/email`で成人向け招待文面を確認する。
3. ユーザー詳細で期限、AI上限、許可理由を設定する。
4. 1回の操作で成人向け全工程を許可し、招待メールを送る。
5. `/admin/adult-monitors`で利用数とフィードバック対応状況を確認する。
6. 異常時は対象者を停止し、必要に応じてDB Kill Switchと環境Flagを停止する。

## 利用者フロー

招待メールから初回案内を開き、18歳以上、禁止範囲、非公開条件を確認する。
その後Webマニュアルに従い、市場分析から順番に進める。

## セキュリティ

- 成人向け各工程はFeature Flag、DB設定、個別許可、本人同意でfail closed。
- 成人向けテキストAIは管理画面でVaultへ保存したGrok APIキーを使用。
- 招待メールはVaultのResend APIキーを共用し、成人向け専用文面を使用。
- APIキー本体、Providerエラー、管理メモを利用者へ表示しない。
- フィードバックは成人向け専用テーブルへ分離する。
