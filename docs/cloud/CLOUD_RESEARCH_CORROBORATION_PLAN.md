# Cloud Research Corroboration Plan

## 目的

2つの検証済み出典から同じ根拠分野の原文候補を抽出し、定量表現が一致する候補、相反する可能性がある候補、関連するが直接比較できない候補を利用者へ示す。

## 原則

- 相反の「可能性」までを検出し、真偽や誤りを自動断定しない
- 同じ単位、同じ指標、同じ時点を確認できる場合だけ定量比較する
- 時点、母集団、指標が不足する候補は比較不能として扱う
- 両方の原文を人が確認するまで事実メモへ保存しない
- 出典本文全文をDB、log、Browser responseへ出さない

## 実装範囲

1. 既存の事実候補から定量表現、年、指標語を抽出する
2. 2出典の候補を組み合わせて保守的に分類・順位付けする
3. 2つ目の検証済みURLを入力できるServer Actionを追加する
4. 比較結果を確認し、出典1・2の事実欄へ明示的に採用するUIを追加する
5. 支持、相反可能性、比較不能を含むgolden setを追加する

## 非対象

- LLM、埋め込み、外部AI API
- 自動ファクトチェック、出典の権威性判定
- 本文、比較結果、候補のDB保存
- Supabase migration
- 市場分析engine、検索Provider、Desktopの変更

## 完了条件

- URLとtopicをServerで再検証する
- 2出典を既存のSSRF防御付き取得処理で検証する
- 同じ定量値を持つ候補を`corroborates`として提示できる
- 同一指標・単位・年で異なる値を持つ候補だけを`potential_conflict`として提示できる
- 時点や指標が揃わない候補を`related`または`insufficient`に留める
- 利用者操作なしにフォームやDBへ転記しない
- golden set、全Hubテスト、型検査、Lint、buildが成功する
