# MANGA 構図コントロール v1

## 目的

一般向けCloud Canvasのコマ画像生成で、ネームを作り直さずに画角、カメラ位置、人物配置、視線方向を調整できるようにする。

## 利用方法

1. Canvasで生成対象のコマを選ぶ。
2. 「AIおまかせ画像生成」の「画角・ポーズを調整（任意）」を開く。
3. 必要な項目だけ変更し、候補を生成する。
4. 生成候補を比較し、採用する。

各項目の初期値は「ネームどおり」である。設定を変更しなければ従来どおりネームの画角、カメラ、構図、視線を使用する。

## 選択項目

- 画角: 顔・表情、上半身、広い画角、全身・ポーズ
- カメラ位置: 目線、俯瞰、あおり、肩越し、躍動的な角度
- 人物配置: 中央、左、右、二人、手前と奥
- 視線方向: カメラ、左、右、会話相手、画面外
- 追加の構図指定: 500文字以内の任意入力

## 安全性と互換性

- APIは列挙済みの値だけを受け付け、任意の制御値を拒否する。
- 構図指定は通常の新規生成だけへ明示的に渡す。既存のImage-to-Image、Inpainting、Outpaintingの操作は変更しない。
- 生成Promptは従来どおり利用者向けJob responseへ返さない。
- DB migration、Feature Flag、Provider、料金設定の追加はない。
- 成人向け、Desktop、Stripe、Marketplaceは変更しない。

## 制約

v1は画像モデルへ明確な構図指示を渡す機能であり、生成結果の完全一致を保証するものではない。採用前に複数候補を比較する。

## 確認項目

- 4種類の選択と追加指定が生成条件へ反映される。
- 初期値では既存のネーム指定が維持される。
- 390px相当で横方向へ固定幅が発生しない。
- 修正、部分修正、画角拡張が従来どおり利用できる。
