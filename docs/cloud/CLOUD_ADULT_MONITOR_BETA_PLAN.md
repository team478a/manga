# Cloud成人向けモニターBeta 実装計画

## 目的

既存購入者1〜3名へPreviewを限定共有し、市場分析から非公開作品管理までを安全に試してもらう。
Shareable Linkを知っているだけでは成人向け機能を利用できず、管理者が登録した有効期限内の
モニターだけが実行できる構造にする。

## 実装範囲

- モニター登録、開始、一時停止、完了、取消
- 市場分析からAIネームまでの権限とモニター登録の一括付与
- 成人向け全工程の一括停止
- モニターごとのAI実行回数上限と利用数
- 成人向けDB RLSへのモニター状態追加
- 利用者フィードバック入力と管理者確認
- 管理者用モニター一覧
- Preview限定公開preflight、受入れ表、緊急停止手順

## 対象外

- 成人向け画像生成
- 成人向け作品公開、Marketplace、販売
- 自動課金、購入連動の自動許可
- 本番公開、既存Draft PRのmerge
- メール、Slack等の外部通知

## 安全条件

成人向け機能は、既存Feature Flag、DB Kill Switch、個別許可、本人同意に加えて、
`CLOUD_ADULT_MONITOR_BETA_ENABLED=true`と有効なモニター登録を必須とする。
AI実行上限はDB transactionで検査・消費し、上限到達後はProvider呼び出し前に停止する。
停止・期限切れ・取消後は、成人向け保存データのRLS参照も拒否する。

## 完了条件

- 管理者が1操作でモニター開始と全工程許可を実行できる
- 管理者が1操作で全工程を停止できる
- 未登録、停止、期限切れ、上限到達をProvider呼び出し前に拒否する
- モニターが評価と自由記述を保存できる
- 管理者がモニター状態、利用数、フィードバックを確認できる
- 所有者と別ユーザーのRLS、responsive、緊急停止をPreviewで受入れできる
