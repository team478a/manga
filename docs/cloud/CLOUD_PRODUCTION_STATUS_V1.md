# Cloud ページ制作状態 v1

## 目的

32ページ以上の制作で、ページごとの作業状態と作品全体の完成度を見失わないようにする。画像生成、確認、修正、確定を一つの制作ボードで管理する。

## 状態

- `not_started`: 未着手
- `generating`: 画像生成Queueが処理中
- `review_required`: 生成または編集後の確認待ち
- `revision_required`: 修正が必要
- `finalized`: 確定。編集と再生成をDB側でも拒否

確定後にキャラクター、画風、場所、小物、参照画像が更新された場合は、制作コンテキストrevisionを比較して「設定変更あり」と表示する。確定状態は自動解除せず、制作者が明示的に編集を再開する。

## UI

- 作品全体の確定率、確定数、要確認・要修正数、生成中数
- すべて／確認が必要／生成中／確定済みフィルター
- ページカード上の状態表示
- 確認待ち、要修正、確定、編集再開の操作
- 確定ページを一括生成の選択対象から除外

## 運用

適用migrationは `202608010005_cloud_production_status.sql`。未適用環境では従来の制作ボードを維持し、状態は未着手として表示する。実DBへの適用は責任者がPreview確認後に行う。
