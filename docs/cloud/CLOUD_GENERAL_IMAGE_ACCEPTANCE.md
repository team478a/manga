# 一般向け画像生成 受入れ手順

## 目的

一般向けCloud漫画制作で、1コマの画像生成から候補採用、保存、出力までを安全に確認する。
成人向け画像生成と本番一斉公開は対象外とする。

## 管理画面の事前条件

`/admin/general-monitors/readiness`で次がすべて「準備完了」であることを確認する。

- 一般向け制作フローのFeature Flag
- 一般向け画像生成Provider（BFL APIキー、モデル、有効状態）
- Cloud AI全体の生成受付
- 選択中モデルの背景・小物・効果・人物用価格
- Worker有効化と32文字以上の署名Secret

画面は秘密値を表示せず、設定済みかどうかだけを判定する。

## 1コマ受入れ

1. スタッフ用の一般向け作品を作成する。
2. 1ページにテスト用コマを1つ用意する。
3. 画像生成を1回だけ依頼し、処理待ち件数が増えることを確認する。
4. `/admin/cloud-ai`からWorkerを1回実行する。
5. 編集画面で候補画像を確認し、採用する。
6. 同じコマで再生成と元に戻す操作を確認する。
7. 保存後に再読み込みし、採用状態が維持されることを確認する。
8. PDFとPNGを出力し、採用画像、コマ枠、吹き出し、文字の重なりを目視確認する。

## 合格条件

- ProviderやDBの内部エラーが利用者へ露出しない。
- 二重送信で同一Jobが増殖しない。
- 失敗時に対象コマだけ再生成できる。
- 候補の採用・再生成・復元が成立する。
- 保存後の再読み込みとPDF／PNG出力で同じ採用画像が使われる。
- 390px、768px、1280pxで主要操作に横スクロールが発生しない。

## 実施しないこと

- APIキー本体の画面表示、ログ出力、文書記載
- 成人向け画像のBFL送信
- 連続した有料API実行
- Feature Flagの本番変更
- 本番一般公開
