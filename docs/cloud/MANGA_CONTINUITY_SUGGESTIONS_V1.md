# MANGAI 連続性設定候補 v1

更新日: 2026-08-01

## 目的

長編作品で設定台帳への転記負担を減らす。確定済みの構造化情報だけから候補を作り、利用者が内容を確認して登録した項目だけを正式な連続性事実として保存する。

## 候補の入力元

- キャラクター設定: 見た目年齢、体格、髪、衣装、配色、固定特徴
- 場所・小物設定: 説明、配色、外見特徴、連続性ルール
- ページに割り当て済みのシーン: シーン名、要約、実際のページ範囲

Provider用Prompt、Negative Prompt、画像の見た目、未確定の本文解釈は候補へ含めない。外部AIや有料APIは呼び出さない。

## 確認フロー

1. 一貫性チェック画面で未登録候補を表示する。
2. 利用者が対象、項目、内容、ページ範囲と抽出元を確認する。
3. 「確認して台帳へ登録」を押した候補だけ、既存の事実保存Actionと所有者限定RPCへ渡す。
4. 同じ内容・同じ範囲が登録済みなら候補から除外する。
5. 登録後はM5-1の矛盾検出対象になる。

## 安全境界

- 自由文から未確認の事実を推測しない。
- 候補そのものはDBへ保存しない。
- フォーム値は既存Zod schemaで再検証し、DBは作品編集権限を再確認する。
- 内部DBエラーやProvider向けPromptを画面へ露出しない。
- migration未適用時も手動登録と既存画像履歴チェックを維持する。

## 外部作業

追加migration、環境変数、Provider credentialは不要。実作品による候補語彙と表示件数の調整は責任者確認後に行う。
