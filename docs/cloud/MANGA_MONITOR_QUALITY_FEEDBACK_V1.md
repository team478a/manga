# MANGAI 限定モニター品質フィードバック v1

更新日: 2026-08-02

## 目的

限定モニターが漫画Editorからページまたはコマを評価し、管理者が採用率、修正率、作り直し率、生成回数、概算費用、所要時間を改善判断に使えるようにする。

## モニター操作

1. ページEditorを開く。
2. 「この原稿を評価」でページ全体またはコマを選ぶ。
3. 「このまま採用」「修正すれば使える」「作り直し」を選ぶ。
4. 修正が必要な場合だけ、顔、手、構図、一貫性、文字、画質などの理由と影響度を選ぶ。
5. 必要に応じてコメントを書き、送信する。

Provider名、モデル名、費用、生成時間は利用者へ入力させず、サーバーが保存済み生成Jobから記録する。

## 管理者表示

既存の一般モニター管理画面へ次を集約する。

- 採用、要修正、作り直しの件数
- ページ番号とコマ名
- 問題種別と影響度
- 1評価当たりの完了生成回数
- Provider／モデル
- 概算費用と生成所要時間

## セキュリティ

- ログイン済みの有効な一般モニターだけが登録できる。
- ページ／コマ評価は、本人が編集可能な作品に限定する。
- project、page、panelの組み合わせをサーバーで再検証する。
- 生成指標はクライアント入力を信用せず、保存済みJobから導出する。
- DB／Provider内部エラーは利用者へ露出しない。
