# MANGA 背景・人物・効果の分離生成 v1

- Draft PR: [#103](https://github.com/team478a/manga/pull/103)
- Preview: `https://mangai-hub-staging-git-agent-manga-la-a0ee14-team478as-projects.vercel.app`

## 目的

一般向けCloud Canvasで、完成コマを毎回一枚として作り直さず、背景・人物・効果を別々に生成、比較、採用できるようにする。

## 利用方法

1. Canvasで対象コマを選ぶ。
2. 「AIおまかせ画像生成」の「生成するレイヤー」を選ぶ。
3. 完成コマ、背景だけ、人物だけ、効果だけのいずれかを生成する。
4. 候補を採用すると、選択した対象に合うコマ内レイヤーとして追加される。
5. レイヤー一覧から表示切替や上下移動を行う。

## 生成対象

- 完成コマ: 従来どおり背景・人物・効果を一枚へ統合する。
- 背景だけ: 人物や効果線を除き、後から人物を重ねる空間を残す。
- 人物だけ: 背景を純白にした漫画線画素材として生成する。
- 効果だけ: 人物と背景を除き、集中線、スピード線、衝撃、光、影などの演出素材を生成する。

## レイヤー採用

- 背景は通常合成で最下部へ追加する。
- 人物と効果は純白地を乗算合成し、下の背景を隠さず重ねる。
- 既存のレイヤーは削除せず、採用ごとに新規レイヤーを追加する。
- 利用者は採用後も表示切替と順序変更ができる。

## 参照情報の分離

- 背景生成: 画風、場所、小物の設定と参照画像だけを利用する。人物参照を送らない。
- 人物生成: 画風、人物設定と人物参照画像だけを利用する。場所・小物参照を送らない。
- 効果生成: 画風を利用し、人物・場所・小物参照を送らない。
- 完成コマ: 従来どおり関連する全設定を利用する。

## 安全性と互換性

- APIは列挙済みの生成対象だけを受け付ける。
- 未指定時は完成コマとなり、既存クライアントとの互換性を維持する。
- 既存Provider、価格設定、Feature Flag、quota、rate limitを再利用する。
- DB migrationは追加しない。
- Image-to-Image、Inpainting、Outpaintingの既存動作は変更しない。
- 成人向け、Desktop、Stripe、Marketplaceは変更しない。

## 制約

v1は白地素材と乗算合成を使う一般向けモノクロ漫画向けの方式である。Providerが完全な純白背景を生成しない場合は、採用後に薄い背景が残る可能性がある。透明背景の自動切り抜きは後続候補とする。

## 確認項目

- 4つの生成対象を選択できる。
- 生成Jobが背景、人物、効果の正しい種別になる。
- 背景生成へ人物参照が混ざらない。
- 人物・効果が乗算レイヤーとして採用される。
- 背景が既存レイヤーの下へ追加される。
- 390px相当で横方向へ固定幅が発生しない。
