# MANGA Longform Readiness v1

## 目的

32〜100ページ作品で、利用者が技術的な状態を調べなくても「次に何をするか」を判断できる完成ガイドを提供します。

## 確認順序

1. 原稿チェックの要修正を解消し、全ページを確定する
2. 復元可能な作業バックアップを作成する
3. 完成版を固定する
4. 完成原稿PDFを書き出す

最初の未完了項目だけを次の操作として案内します。全項目が揃うと「完成準備完了」と表示します。

## 判定契約

- 原稿: 完成用preflightが成功し、要修正が0件
- 復旧: checkpointとrestore機能が利用可能で、固定版が1件以上
- 完成版: `release`種別の固定版が1件以上
- PDF: download可能な完了Exportが1件以上
- 機能未適用または取得失敗は完了扱いにせず、安全に準備確認へ案内

## 実装境界

- 既存の原稿preflight、Export履歴、checkpoint履歴だけを利用する
- 新規migrationなし
- 新規環境変数なし
- 外部Provider呼び出しなし
- APIキー、Provider、モデル、内部単価は表示しない

## 検証待ち

- 実ブラウザでのanchor移動と390px表示
- 実作品で原稿修正から完成PDFまでの状態遷移
- 100ページfixture
- 責任者承認
