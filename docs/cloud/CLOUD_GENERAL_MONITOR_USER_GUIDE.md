# MANGAI Cloud 一般向けモニター Webご利用ガイド

## はじめに

このモニターでは、一般向け漫画の制作フローを無料で試せます。
市場や販売の専門知識は必要ありません。作りたい方向を選ぶと、AIが売れやすさを分析し、
企画、シナリオ、ネーム、原稿編集、作品管理へ順番に引き継ぎます。

モニター期間中はStripe、決済、販売申請を使用しません。成人向け作品は対象外です。

## 1. ログイン後に確認すること

1. 招待されたメールアドレスでログインします。
2. ダッシュボードの「限定モニター」で、期限とAI利用数を確認します。
3. 「市場分析を開始」を押します。

AI利用数は、市場分析、企画、シナリオ、ネーム、コマ画像の生成時に消費します。
同じボタンを続けて押さず、生成中は画面を閉じずにお待ちください。

## 2. 市場分析

1. 「ジャンル」と「テーマ・読後感」を選びます。
2. 迷った項目は「AIにおまかせ」のままで構いません。
3. 決まっている場合だけ「作りたいイメージ」を入力します。
4. 「どんな作品が売れやすいか調べる」を押します。
5. 結果の「売れやすい方向」「想定読者」「価格」「販売先」「注意点」を確認します。

出典URLや市場データを利用者が入力する必要はありません。

## 3. AI企画提案

1. 市場分析結果の「AI企画提案の準備へ」を押します。
2. 「AI企画を3案作成」を押します。
3. 「本命案」「差別化案」「小さく試す案」を比較します。
4. 売れやすさ、作りやすさ、独自性、買われる理由を確認します。
5. 制作したい企画を1つ選びます。

## 4. シナリオ作成

1. 「シナリオ生成へ進む」を押します。
2. 「AIで初稿シナリオを作る」を押します。
3. 人物、三幕構成、シーン、ページ配分を確認します。
4. 修正したい場合は指示を入力して修正版を作ります。
5. 使用するシナリオを採用します。

## 5. ネーム作成

1. 採用シナリオから「AIネーム生成へ進む」を押します。
2. 「AIで初稿ネームを作る」を押します。
3. ページ、コマ割り、構図、セリフを確認します。
4. 必要に応じて修正版を作り、使用するネームを採用します。
5. 「Canvas下書きを作成」を押します。

## 6. 原稿編集

Canvasではコマ枠、吹き出し、テキストを編集できます。保存表示を確認してから移動してください。
コマ画像生成を利用できる場合は、必要なコマだけ生成してください。

最初から長編全体を生成せず、まず4〜8ページで次の一巡を試してください。

1. 作品を作成する
2. 人物と画風を設定する
3. ページを開いてコマ画像を生成する
4. 候補を比較して採用する
5. ページを確認・確定する
6. PDFを書き出す

## 7. 人物・画風・世界観を固定する

作品画面から、画像生成前に次を保存します。

- 「外見・衣装の設定を編集」：髪型、体格、衣装、変えたくない特徴
- 「画風・場所・小物を設定」：作品全体の画風、色、場所、小物
- 「参照画像とコマ割当」：顔、衣装、画風、背景、小物の見本画像

参照画像を登録する前に、対象となるキャラクター、画風、場所、小物を保存してください。
必要な人物・場所・小物をコマへ割り当てると、ネーム上の表記にかかわらず生成条件として優先されます。

## 8. 章・話・シーン・ページを整理する

作品画面で章を追加し、章の中に話、シーン、ページを並べます。
最初は4〜8ページで操作を確認し、問題がなければ32ページ、最終的に最大100ページまで増やします。

- ページを開く前に章とシーンの大まかな流れを決める
- ページの順番を変更した場合はページ番号を確認する
- 章ごとに優先度、担当名、期限、メモを保存する
- 「長編コックピット」で次に着手する章と期限超過を確認する

## 9. コマ画像を生成する

1. 作品画面から編集するページを開きます。
2. 生成対象のコマを選びます。
3. 必要に応じて完成コマ、背景、人物、効果のレイヤーを選びます。
4. 候補数と構図を選び、生成ボタンを1回だけ押します。
5. 候補を比較し、使用する画像だけをコマへ採用します。
6. 保存完了を確認してから別画面へ移動します。

顔、手、衣装、背景など一部分だけ直したい場合は修正候補を使用します。
元の採用画像は残るため、比較してから採用できます。

## 10. 一括生成と制作状態

作品画面では4〜8ページを選んでまとめて生成できます。

- 「未着手」：まだ制作を始めていない
- 「生成中」：画像生成の完了待ち
- 「要確認」：生成結果を確認する
- 「要修正」：修正して再確認する
- 「確定」：完成ページとして編集を止める

確定後に人物・画風・参照設定を変更した場合は、ページを再確認してください。
確定ページを直す場合は「編集を再開」を押します。

## 11. 連続性と伏線を確認する

「一貫性をチェック」では、人物、衣装、場所、小物、口調、時系列、伏線を確認します。
システムが示す候補は、内容を確認して登録したものだけが正式な事実になります。

「長編コックピット」では次を一画面で確認できます。

- 章・シーン・ページの進捗
- 要確認・要修正・確定ページ
- 設定の矛盾候補と未回収の伏線
- 章の優先度、期限、次に着手する章

## 12. 完成原稿PDF

PDF書き出しを始める前に、次を確認してください。

1. 原稿チェックの修正項目を解消する
2. 生成中の処理が残っていないことを確認する
3. すべてのページを「確定」にする
4. 「PDF書き出しを開始」を1回押す
5. 完了後に「PDFをダウンロード」を押す

長編PDFは分割して処理されます。画面を閉じても処理は継続し、途中から再開できます。

## 13. 作品管理

「作品管理」では、制作した作品の状態と公開準備状況を一覧で確認できます。
販売準備と収益管理は現在「準備中」であり、今回のモニターテスト対象外です。

## 14. 一般向け漫画を外部販売用に準備する

現在のMANGAI Cloudでは、一般向け漫画を完成原稿PDFまで作成できます。
MANGAI内の販売申請、決済、収益管理は準備中です。販売する場合は、ダウンロードした原稿を
Kindle Direct Publishing（KDP）やBOOTHなどの外部販売サイトへご自身で登録してください。
この手順は売上を保証するものではなく、成人向け作品は対象外です。

出品前に次を確認します。

1. 全ページを確定し、PDFを最初から最後まで開いてページ順と文字を確認する
2. タイトルと作者名を入れた表紙・商品画像を別に保存する
3. タイトル、作者名、紹介文、ジャンル、タグ、価格、対象年齢を決める
4. 第三者の著作物、商標、肖像、個人情報を無断で使用していないことを確認する
5. 販売サイトのAI生成コンテンツ申告、規約、手数料を出品直前に確認する
6. 原稿、表紙、紹介文、公開日、販売URLを同じ版として手元にも保存する

## 15. 外部販売サイトへ出品する共通手順

1. MANGAIから完成原稿PDFを保存し、表紙と商品紹介画像を準備します。
2. 商品情報を下書きします。
3. 販売サイトのご自身のアカウントで商品情報、表紙、原稿を登録します。
4. 本人確認、振込先、税務情報は販売サイト上でご本人が入力します。
5. ページ順、文字、見開き、表紙、価格、公開範囲をプレビューします。
6. 必要な権利・AI利用申告を正確に行い、公開または審査へ提出します。
7. 販売URL、公開日、原稿版、価格、売上、手数料、入金を記録します。

商品情報には、少なくとも次を用意してください。

- 基本情報: タイトル、作者名、巻数、言語、対象年齢
- 紹介文: 一文紹介、詳しい紹介、ページ数、ファイル形式
- 検索情報: ジャンル、カテゴリ、タグ、読者に伝える特徴
- 販売条件: 価格、販売地域、公開日、改訂版の扱い
- 権利確認: 使用素材、フォント、参照画像、第三者権利
- AI利用表示: 各販売サイトの質問と規約に従った正確な申告

## 16. Kindle Direct Publishing（KDP）

1. ページ順が分かる連番のPDFまたはPNG/JPEGを準備します。
2. Kindle Createへ原稿を取り込み、漫画用のKPFを書き出します。
3. 更新に備え、編集用のKCBプロジェクトも手元へ保存します。
4. Kindle Previewerでページ順、文字、見開き、表紙を確認します。
5. KDPで書誌情報、権利、販売地域、価格、表紙、KPFを登録します。
6. AI生成画像を含む場合は、KDPの質問へ正確に申告して提出します。

公式情報:

- [Kindle Createでのマンガ準備](https://kdp.amazon.co.jp/ja_JP/help/topic/GJMRD9F78MS9F43R)
- [Kindle電子書籍の対応ファイル形式](https://kdp.amazon.co.jp/ja_JP/help/topic/G200634390)
- [Kindle Previewer](https://kdp.amazon.co.jp/ja_JP/help/topic/G202131170)
- [AI生成コンテンツの申告を含むKDPコンテンツガイドライン（英語）](https://kdp.amazon.com/en_US/help/topic/G200672390)

## 17. BOOTHのダウンロード商品

1. BOOTHでショップ名、紹介文、オーナー情報、振込先を設定します。
2. 商品種別で「ダウンロード商品」を選びます。
3. 商品名、商品画像、カテゴリ、紹介文、価格を入力します。
4. 完成原稿PDFをアップロードし、内容と規約を再確認して公開します。
5. 公開後に商品ページを開き、画像、説明、価格、販売ファイルを確認します。
6. 差し替え時は先に新しいファイルを追加し、購入者への案内を検討します。

ファイル容量、サービス利用料、禁止商品、公開範囲は変更される場合があります。
出品時に最新画面と公式ヘルプを正本として確認してください。

公式情報:

- [BOOTHで作品を売る手順](https://booth.pm/guide)
- [BOOTHダウンロード販売ヘルプ](https://booth.pixiv.help/hc/ja/sections/115000543514-%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89%E8%B2%A9%E5%A3%B2%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)
- [ダウンロードファイルの差し替え](https://booth.pixiv.help/hc/ja/articles/115003627093-%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%82%92%E5%B7%AE%E3%81%97%E6%9B%BF%E3%81%88%E3%82%8B%E6%96%B9%E6%B3%95%E3%81%8C%E7%9F%A5%E3%82%8A%E3%81%9F%E3%81%84)

## 18. 販売後に記録すること

- 販売サイトと販売URL
- 公開日、原稿版、価格、変更履歴
- 売上、サービス利用料、振込額、入金日
- 問い合わせと対応内容
- 修正版を公開した日と購入者への案内

MANGAI内の収益管理は準備中です。それまでは販売サイトの売上画面と、ご自身の帳簿を正本として管理してください。
税務・法務の判断が必要な場合は、最新の公的情報や専門家へ確認してください。

## 19. スマートフォンでの操作

- 制作工程のメニューは横へ動かすと続きが表示されます。
- ボタンは1回だけ押し、「処理中」の表示が消えるまで待ってください。
- 保存完了を確認してから別画面へ移動してください。
- 古い表示が残る場合は画面を再読み込みしてください。

## 20. フィードバック

ダッシュボードの「状況・ご意見」から、工程、評価、結果、コメントを送信できます。
特に次の情報があると改善に役立ちます。

- 迷った画面やボタン
- 期待と違った結果
- 途中で進めなかった工程
- 良かった提案や便利だった操作
- 使用端末と画面サイズ

パスワード、APIキー、個人情報はコメントへ入力しないでください。

## 困ったとき

- 「招待が必要です」：招待されたアカウントか確認してください。
- 「現在停止中」：運営側で安全確認のため一時停止しています。操作を繰り返さずスタッフへご連絡ください。
- AI利用上限：管理者へ追加確認を依頼してください。
- 生成が終わらない：連打せず、少し待ってから一度だけ再試行してください。
- PDFを開始できない：全ページの確定、原稿チェック、生成中処理の有無を確認してください。
- 表示が崩れる：画面を再読み込みし、直らなければスクリーンショットと端末情報をお知らせください。

モニター期間、利用状態、残りAI利用数は「状況・ご意見」で確認できます。

## Webマニュアル

ログイン後、次の画面から最新版を確認できます。

- 利用者向け: `/dashboard/monitor/guide`
- モニター状況・フィードバック: `/dashboard/monitor`

制作画面のサイドバーにある「使い方」から、いつでも最新版を開けます。

Webマニュアルには、最初の5分で行うこと、各工程の入力・操作・完了の目印、
トラブル対応、安全上の注意を掲載しています。スマートフォンでは上部の
メニューを横へ動かして各項目へ移動できます。

「画面で確認」では、ダッシュボード、市場分析からネームまでの流れ、原稿編集の
事前設定、ページ一括生成の見積り、完成原稿PDF、外部販売用ファイル準備の順に画面例を確認できます。
画面例は実画面を基にしつつ、個人名、作品内容、利用枠を含まない表示へ匿名化しています。
実際の件数、料金、残り利用数は操作時の画面を正本として確認してください。
