# MANGAI Cloud 一般向けモニター Webご利用ガイド

## はじめに

このモニターでは、一般向け漫画の制作フローを無料で試せます。
市場や販売の専門知識は必要ありません。作りたい方向を選ぶと、AIが売れやすさを分析し、
企画、シナリオ、ネーム、原稿編集、作品管理へ順番に引き継ぎます。

モニター期間中はStripe、決済、販売申請を使用しません。成人向け作品は対象外です。

## 1. ログイン後に確認すること

1. 招待されたメールアドレスでログインします。
2. ダッシュボードの「限定モニター」で、期限とAI利用数を確認します。
3. 「市場分析を開始」を押します。

AI利用数は、市場分析、企画、シナリオ、ネーム、コマ画像の生成時に消費します。
同じボタンを続けて押さず、生成中は画面を閉じずにお待ちください。

## 2. 市場分析

1. 「ジャンル」と「テーマ・読後感」を選びます。
2. 迷った項目は「AIにおまかせ」のままで構いません。
3. 決まっている場合だけ「作りたいイメージ」を入力します。
4. 「どんな作品が売れやすいか調べる」を押します。
5. 結果の「売れやすい方向」「想定読者」「価格」「販売先」「注意点」を確認します。

出典URLや市場データを利用者が入力する必要はありません。

## 3. AI企画提案

1. 市場分析結果の「AI企画提案の準備へ」を押します。
2. 「AI企画を3案作成」を押します。
3. 「本命案」「差別化案」「小さく試す案」を比較します。
4. 売れやすさ、作りやすさ、独自性、買われる理由を確認します。
5. 制作したい企画を1つ選びます。

## 4. シナリオ作成

1. 「シナリオ生成へ進む」を押します。
2. 「AIで初稿シナリオを作る」を押します。
3. 人物、三幕構成、シーン、ページ配分を確認します。
4. 修正したい場合は指示を入力して修正版を作ります。
5. 使用するシナリオを採用します。

## 5. ネーム作成

1. 採用シナリオから「AIネーム生成へ進む」を押します。
2. 「AIで初稿ネームを作る」を押します。
3. ページ、コマ割り、構図、セリフを確認します。
4. 必要に応じて修正版を作り、使用するネームを採用します。
5. 「Canvas下書きを作成」を押します。

## 6. 原稿編集

Canvasではコマ枠、吹き出し、テキストを編集できます。保存表示を確認してから移動してください。
コマ画像生成を利用できる場合は、必要なコマだけ生成してください。

## 7. 作品管理

「作品管理」では、制作した作品の状態と公開準備状況を一覧で確認できます。
販売準備と収益管理は現在「準備中」であり、今回のモニターテスト対象外です。

## 8. スマートフォンでの操作

- 制作工程のメニューは横へ動かすと続きが表示されます。
- ボタンは1回だけ押し、「処理中」の表示が消えるまで待ってください。
- 保存完了を確認してから別画面へ移動してください。
- 古い表示が残る場合は画面を再読み込みしてください。

## 9. フィードバック

ダッシュボードの「状況・ご意見」から、工程、評価、結果、コメントを送信できます。
特に次の情報があると改善に役立ちます。

- 迷った画面やボタン
- 期待と違った結果
- 途中で進めなかった工程
- 良かった提案や便利だった操作
- 使用端末と画面サイズ

パスワード、APIキー、個人情報はコメントへ入力しないでください。

## 困ったとき

- 「招待が必要です」：招待されたアカウントか確認してください。
- 「現在停止中」：運営側で安全確認のため一時停止しています。操作を繰り返さずスタッフへご連絡ください。
- AI利用上限：管理者へ追加確認を依頼してください。
- 生成が終わらない：連打せず、少し待ってから一度だけ再試行してください。
- 表示が崩れる：画面を再読み込みし、直らなければスクリーンショットと端末情報をお知らせください。

モニター期間、利用状態、残りAI利用数は「状況・ご意見」で確認できます。

## Webマニュアル

ログイン後、次の画面から最新版を確認できます。

- 利用者向け: `/dashboard/monitor/guide`
- モニター状況・フィードバック: `/dashboard/monitor`

制作画面のサイドバーにある「使い方」から、いつでも最新版を開けます。

Webマニュアルには、最初の5分で行うこと、各工程の入力・操作・完了の目印、
トラブル対応、安全上の注意を掲載しています。スマートフォンでは上部の
メニューを横へ動かして各項目へ移動できます。
