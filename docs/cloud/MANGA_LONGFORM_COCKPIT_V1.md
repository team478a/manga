# 長編作品コックピット v1

## 目的

32〜100ページ作品で、章・シーン・ページ制作状態・伏線・人物関係を一画面から確認できるようにする。

## 実装範囲

- 作品別URL: `/creator/[projectId]/cockpit`
- 全ページ、確定、生成中、確認・修正待ち、完成率の集計
- 章／シーンごとのページ配置と制作状態
- 未回収の伏線と一貫性警告
- 登録済み人物と、確定済みの関係・時系列台帳
- ページ編集、一貫性台帳、人物設定への導線

表示対象は保存済みデータに限定する。新しい物語設定の推測、Provider呼び出し、外部AI分析は行わない。

## 障害時の挙動

制作状態、連続性台帳、人物設定の追加テーブルを読み込めない場合も、作品・章・シーン・ページ構造は可能な範囲で表示する。DB migrationと環境変数の追加は不要。

## 次の候補

- 章・話単位のフィルターと折りたたみ
- 100ページ向け仮想化一覧
- シーン単位の制作優先度と担当管理
- 下流成果物の古さ（stale）を章単位で集約
