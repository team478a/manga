長編制作migrationはリポジトリのmanifest、rollback、canonical schemaへ統合済みである。
過去の適用記録では、2026-07-31〜2026-08-02の漫画制作migrationについてtable、RPC、RLS、trigger、bucketの確認が完了している。

今後、既存migrationを再適用したり、同じ機能を別IDで追加したりしない。
