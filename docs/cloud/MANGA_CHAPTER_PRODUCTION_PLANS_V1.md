# MANGA Chapter Production Plans v1

更新日: 2026-08-01

## 目的

32〜100ページの長編制作で、章ごとの優先度、担当名、期限、作業メモを作品コックピットから管理する。

## 実装

- 章ごとに「低・通常・高・最優先」の優先度を保存
- 担当名、期限、作業メモを保存
- 未完了章の期限超過を表示
- 優先度と期限から「次に着手する章」を決定的に表示
- 所有者の作品だけを参照・更新できるRLS/RPC
- migration未適用時は既存コックピットを維持し、安全な案内を表示
