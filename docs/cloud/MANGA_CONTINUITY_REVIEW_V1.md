# 漫画生成 一貫性チェック v1

## 目的

一般向けCloud漫画で採用した生成画像が、作品内の人物・衣装・場所・小物・画風の固定設定を継続して使用しているか確認する。

## 利用者画面

- 作品詳細の「一貫性をチェック」から開く
- 採用済み生成画像数、生成履歴確認済み数、要確認数を表示
- 問題のあるページへ直接移動できる
- 参照画像とコマ割当の修正画面へ移動できる
- 対象がない場合、DB未適用時、問題なしの場合を個別表示する

## 判定内容

- コマへ割り当てた人物・場所・小物の設定版が生成Jobに保存されているか
- 生成時の設定版が現在版と一致するか
- 同じ固定対象に複数の設定版が混在していないか
- 登録済み参照画像が生成Jobへ渡されたか
- 作品の画風設定と画風参照画像が生成Jobへ渡されたか
- ページ原稿に保存された生成Job IDから監査可能か

判定はCanvas原稿、生成Job入力、現在のProfile/Bible、参照画像、コマ割当を所有者RLSの範囲で照合する。Provider内部情報、Prompt、署名URL、秘密値は画面へ表示しない。

## 判定しない内容

この版は画像ピクセルを解析しないため、顔・手・衣装・背景が実際の見た目として一致していることは保証しない。画面にも「画像の見た目そのものを判定する機能ではない」と明示する。将来、許可した一般向け画像だけを対象にVision評価を追加する場合も、この履歴検査とは分離する。

## データと境界

- 新規migrationなし
- 既存Canvas `PanelLayer.sourceJobId` と `cloud_generation_jobs.input` を利用
- 既存Character Profile、Style Bible、World Profile、Visual Reference、Panel Assignmentを利用
- 一般向けCloudのみ。成人向け、Desktop、Provider、Worker、Stripe、Marketplaceは変更しない

## 受入れ条件

1. 現在版の人物・画風・参照画像を使う採用画像は警告なしになる。
2. 古い設定版、設定未使用、参照画像未使用をページ単位で警告する。
3. 同じ対象の複数version混在を作品単位で警告する。
4. 警告からページ編集または参照画像設定へ移動できる。
5. 内部エラーを利用者へ露出しない。
