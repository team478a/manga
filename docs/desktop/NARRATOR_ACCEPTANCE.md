# Windows Narrator アクセシビリティ受入れ

更新日: 2026-08-28

## 1. 目的

axeで自動判定できない読み上げ、focus順、ネイティブ確認画面、Windows高コントラストをRC前に手動確認します。自動監査は`npm run desktop:test:a11y`で実施し、この文書ではWindows Narrator固有の挙動を記録します。

## 2. 前提

- 製品版または`npm --prefix apps/desktop start`
- Windows表示倍率100%と150%の両方
- 日本語・Englishの両locale
- Narratorを`Windows + Ctrl + Enter`で開始
- マウスを使用せず、Tab、Shift+Tab、矢印、Enter、Space、Escapeを中心に操作

記録:

| 項目                    | 値               |
| ----------------------- | ---------------- |
| 確認日                  |                  |
| 確認者                  |                  |
| Windows version / build |                  |
| MANGAI version / commit |                  |
| 表示倍率                | 100% / 150%      |
| locale                  | 日本語 / English |

## 3. RC停止条件

次のいずれかがあればRCを停止します。

- 操作可能要素の名前・役割・状態が読み上げられない
- keyboardだけでは画面やダイアログから退出できない
- modal表示中に背面操作へfocusが移動する
- エラー、完了、進捗の重要通知が読み上げられない
- focus位置が視覚的に識別できない
- 通常文字のコントラスト不足を目視確認した

## 9. 判定

自動preflight（2026-08-28）:

- Windows 11 Home 25H2 build 26200で、製品プロセスだけを150%相当（devicePixelRatio 1.5）と強制カラー（forced colors active）へ隔離起動した。
- 両条件で29画面のblocking axe violation 0、document横あふれ0、主要visual／keyboard check 21/21を確認した。
- 初回強制カラーで検出したsystem color未追従を修正し、再実行で解消した。
- 詳細は`docs/RELEASE_CANDIDATE_WINDOWS_DISPLAY_PREFLIGHT_20260828.md`。実Windows設定とNarrator音声の人手確認は未完了のため、以下のRC判定は保留を維持する。
