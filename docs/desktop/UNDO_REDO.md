# Undo / Redo・操作履歴

更新日: 2026-07-13

## 概要

MANGAI Desktopのワークスペースでは、編集操作をProject単位でSQLiteへ保存し、再起動後も元に戻す・やり直すことができます。上部ツールバーの「操作履歴」から直近50件の名称、時刻、取消状態を確認できます。

## 操作方法

- 「元に戻す」ボタンまたは `Ctrl+Z`
- 「やり直す」ボタン、`Ctrl+Y` または `Ctrl+Shift+Z`
- 入力欄の編集中はブラウザー標準の文字Undoを優先するため、アプリ全体のショートカットは動作しません。

## 対象操作

- Project名と表紙の変更
- Episodeの追加、名称変更、並び替え、削除
- Pageの追加、複製、並び替え、削除
- PageのPrompt、Negative Prompt、メモ編集
- Canvasのコマ、吹き出し、テキストの追加、削除、移動、変形、スタイル変更
- 素材割り当て、画像配置、レイヤー順、表示、ロック
- ページテンプレート適用と複数オブジェクト操作

Episode、Page、Panel、Balloon、Text Objectの状態を編集スナップショットとして保存します。Canvasスナップショットv2は旧履歴との後方互換を維持します。Undo後に新しい編集を行った場合、その時点より先のRedo履歴は破棄されます。

ドラッグと変形は終了時、本文は600msのデバウンス後に1件の履歴として保存します。テンプレートと複数選択操作は一括保存し、1回のUndoで戻します。

## 対象外

素材のインポート・削除、AI生成、書き出し、AI設定はUndo対象外です。これらはファイル操作、外部処理、アプリ全体設定を伴うため、Project編集履歴とは分離しています。

## SQLite

`operation_history`テーブルへProject ID、操作名、変更前後のJSON、取消状態、作成日時を保存します。Projectを削除すると関連履歴も削除されます。
