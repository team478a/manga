# 漫画編集Canvas MVP

更新日: 2026-07-14

## 現在の判定

MANGAI Desktopで、矩形コマ、素材画像、吹き出し、縦書き・横書きテキスト、レイヤー、テンプレート、Undo/Redo、PDF・画像ZIP書き出しの基本経路を利用できます。

完了条件33項目と4つの手動受け入れシナリオを満たしています。クリーンWindows環境でのインストール確認が残るため、配布まで含む漫画編集Canvas MVP全体の判定は「一部完了」です。個別判定は [`MANGA_EDITOR_IMPLEMENTATION_STATUS.md`](MANGA_EDITOR_IMPLEMENTATION_STATUS.md) を参照してください。

## 対応機能

### コマと画像

- 矩形コマの追加、選択、移動、リサイズ、回転、複製、削除
- ページ上のドラッグによる任意サイズのコマ作成とEscapeキャンセル
- 位置、寸法、名称、境界線、背景色の編集
- 素材の割り当て、差し替え、解除
- 素材一覧からドロップ先コマへの直接ドラッグ＆ドロップ
- `cover`、`contain`、`manual`の画像配置
- 画像倍率、オフセット、回転、不透明度
- ダブルクリックまたはプロパティから開始するCanvas内画像編集モード
- 画像の直接移動、四隅ハンドルでの拡縮、回転、中央リセット、Escape終了
- コマ領域での画像クリッピング
- ページ端、中央、他オブジェクトへのスナップとガイド
- 100pxグリッド表示、グリッド吸着、全スナップのON/OFF
- Shift選択による複数オブジェクトの一括移動、複製、削除

### 吹き出しとテキスト

- 楕円、角丸、ナレーション枠
- 8方向のしっぽと位置調整
- 吹き出し作成時の子テキスト自動生成
- 自由テキストと吹き出し親子設定
- 吹き出し移動・リサイズ時の子テキスト追従と領域再計算
- 横書き、縦書き、文字サイズ、色、揃え
- grapheme単位の文字分割と縦書き用句読点・括弧表示
- 行頭・行末の基本禁則と半角2桁数字の自動縦中横
- `｜親文字《よみ》`記法による縦書き・横書きルビのCanvas・書き出し表示
- 日本語全角・ASCII半角を考慮した横書き折り返しとルビ親文字の分割防止
- 600msデバウンス保存と文字あふれ警告

### レイヤーとテンプレート

- コマ、吹き出し、テキストの統合一覧
- ドラッグハンドルによる任意位置への並び替え
- 前後移動、表示、ロック、選択
- 1コマ全面、縦2分割、横2分割、上1＋下2、4コマ、6コマ
- 既存コマの置換・追加と、テンプレート適用の単一Undo

### 書き出し

- Page原寸の合成PNG
- JPG、PNG、WebP素材の混在
- SVG合成前に使用中のWebPだけをPNGへ正規化し、PDF・ZIPでの画像欠落を防止
- Episode・Page正式順の連番PNG ZIP
- DPIから物理サイズを算出するPDF
- 非表示レイヤーの除外
- ページ単位の進捗、キャンセル、失敗理由
- Canvasを持たない旧Page画像の全面背景互換

## 画面と操作

- 左: Project、Episode、Page、素材
- 中央: ページCanvas、ズーム、Canvas追加操作
- Canvas右: 統合レイヤーと選択オブジェクトのプロパティ
- アプリ右: Project、Page、素材の既存情報
- 上部: Undo/Redo、操作履歴、インポート、AI、書き出し、設定

上部の「素材パネル」「情報パネル」とCanvasツールの「レイヤー」で、3つの補助領域を個別に開閉できます。開閉状態は端末へ保存され、次回起動時も維持されます。狭いウィンドウでは初回表示時に補助領域を減らし、中央Canvasを優先します。

Canvas上部の操作は機能別に整理しています。

- 「＋ 追加」: コマ、ドラッグ式コマ、吹き出し、テキスト
- 「レイアウト」: 6種類のページテンプレート
- 「表示」: グリッド、スナップ、グリッド吸着、レイヤー表示
- 選択中の削除、画像編集、素材配置はメニュー外へ表示

基本操作:

1. EpisodeへPageを追加します。
2. 「レイアウト」からテンプレートを選ぶか、「＋ 追加」からコマを追加します。「コマを描く」ではページ上をドラッグし、作成モードはEscapeで解除できます。
3. 左の素材をコマへドラッグ＆ドロップします。素材とコマを選び「素材を配置」する操作も利用できます。
4. 画像入りコマをダブルクリックするか、プロパティの「Canvasで画像を編集」を押します。画像をドラッグし、四隅と回転ハンドルで調整します。「画像編集を完了」またはEscapeで終了します。
5. 「＋ 追加」から吹き出しまたはテキストを追加します。
6. レイヤーまたはCanvasで要素を選び、プロパティを編集します。
7. 上部の「書き出し」でPDFと画像ZIPを生成します。

ルビは、本文で親文字を選択し、読みを入力して「ルビを追加」を押します。`｜漫画《まんが》`の記法が挿入され、CanvasとPDF・画像ZIPでは「漫画」を本文として配置し、縦書きでは右側、横書きでは上側へ「まんが」を小さく表示します。横書きの親文字は行末で分割せず、まとまって次行へ送ります。解除する場合は記法内へカーソルを置いて「解除」を押します。閉じていない記法などは通常の本文として保持します。

レイヤー順は一覧左端の「⠿」をドラッグし、緑色の挿入線へドロップして変更します。前面／背面ボタンも引き続き利用できます。並び替え全体は1回のUndoで戻せます。

位置合わせには「# グリッド」「スナップ」「グリッド吸着」を使用します。グリッド間隔はページ座標で100pxです。「スナップ」をOFFにすると、ページ端・中央・他オブジェクト・グリッドへの吸着をまとめて無効化します。

## ショートカット

- `Ctrl+Z`: Undo
- `Ctrl+Y` / `Ctrl+Shift+Z`: Redo
- `Delete` / `Backspace`: 選択を削除
- `Ctrl+D`: 選択を複製
- 矢印キー: 1px移動
- `Shift` + 矢印キー: 10px移動
- Shiftクリック: 複数選択の追加・解除

入力欄へフォーカス中と、ロック済み要素を含む選択ではCanvasショートカットを抑止します。

ツールメニューはTabでフォーカスし、EnterまたはSpaceで開閉できます。メニュー内はTabまたは上下矢印で移動し、Home・Endで先頭・末尾へ移動、Escapeで閉じてメニューボタンへ戻ります。画面の別領域をクリックしても閉じます。

## データ構造と保存

- 正本はSQLiteの`pages`、`panels`、`balloons`、`text_objects`です。
- 吹き出し内テキストの位置・寸法は、親の幅と高さを1とする相対比率を`relative_x`、`relative_y`、`relative_width`、`relative_height`へ保存します。
- Canvas・IPC・書き出し時は相対比率からPage原寸座標を導出します。自由テキストはPage座標を正本とします。
- Canvas内部JSONは永続データの正本にしません。
- 座標と寸法は表示倍率に依存しないPage原寸ピクセルです。
- Canvas IPC入力は`@mangai/canvas-core`のZod schemaで検証します。
- DBマイグレーション前に旧SQLiteをバックアップし、`schema_migrations`で適用済み版を管理します。
- drag/transformは操作終了時に保存し、文字本文はデバウンス保存します。
- rendererはSQLiteやNode.js APIを直接利用せず、contextBridge経由でmain processへ依頼します。

## Undo / Redo

Canvasスナップショットv2はPage設定、Panel、Balloon、Text、z-index、表示、ロック、親子IDを保存します。画像ファイル本体とBase64は履歴へ含めません。旧スナップショットは後方互換で読み込みます。

複数移動・複製・削除、テンプレート適用、吹き出しと子テキストの削除は一括保存し、1回のUndoとして扱います。

## 制限事項・既知の問題

- 分離禁止文字などの高度な禁則、ルビの詳細位置・サイズ指定、3桁以上を任意指定する縦中横、商用フォント同梱は対象外です。行頭・行末の基本禁則、半角2桁数字の縦中横、明示記法による縦書き・横書きルビは自動適用します。
- Canvas領域はPage原寸×ズームでスクロールします。大きなPageや高倍率では横スクロールが必要ですが、素材・情報・レイヤーパネルを閉じて表示領域を広げられます。
- rendererのVite chunkが500kBを超える警告が残っています。
- 30オブジェクトPageは、製品版で選択・移動・リサイズ・保存・再読込を実操作確認済みです。クリーンWindowsへのインストールは未確認です。
