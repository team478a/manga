# MANGAI Desktop Adult 招待制モニター公開計画

作成日: 2026-08-31

## 1. 目的

MANGAI Desktop Adultのローカル制作機能を、対象環境を満たす少人数へ招待制で提供し、一般公開前に導入、生成、部分修正、保存、書き出し、復元の実用性を確認する。

本計画は成人向けCloud Creatorを公開するものではない。成人向けProject、Prompt、参照画像、生成画像、完成PageをMANGAI Cloud、一般向けCloud AI、Cloud Storageへ送信しない既存境界を維持する。

## 2. Pilot範囲

- 対象人数: 第1段階1名、第2段階最大3名、第3段階最大5名。
- 対象端末: Windows 11、専用GPU、VRAM 12GB以上、十分なローカル空き容量。
- AI実行: localhostのOllamaとComfyUIだけ。成人向け外部Providerは無効。
- 生成単位: 1操作1枚、同時実行1件。一括生成は無効。
- 対象機能: Text-to-Image、Image-to-Image、ControlNet、Inpainting、顔・手の範囲修正、素材保存、Page配置、PDF／画像／Project JSON書き出し、バックアップ／復元。
- 対象外: Cloud同期、Cloud保存、Marketplace公開、販売申請、決済、外部Provider、無人一括生成、スマートフォン制作。

12GB以上への限定は初回Pilotの対応範囲であり、Phase 5正式完了条件を変更しない。8GB、12GB、16GB以上の3区分すべての実機証跡が揃うまで、Desktop Adult全体を正式RC完了とは判定しない。

## 3. 公開前の必須条件

次の全条件が揃うまで招待を開始しない。

1. 信頼された証明書でinstallerと製品EXEを署名し、Authenticodeが`Valid`である。
2. 対象version、installer、blockmap、SBOM、checksumを固定し、改変検査に成功する。
3. Pilotと同等のWindows 11／VRAM 12GB以上環境で4生成方式、保存、Page配置、PDF、バックアップ／復元を完走する。
4. 対応ComfyUI version、model、VAE、workflow、必要容量、導入元、利用条件を固定する。
5. 18歳以上、禁止入力、ローカル保存、外部送信なし、自己責任のバックアップ範囲を開始前に明示する。
6. Prompt、Negative Prompt、参照画像、mask、生成画像、自由記述を診断・クラッシュ報告へ含めないことを再確認する。
7. 緊急停止、配布停止、version失効、問い合わせ、アンインストール、作品データ保持の手順を用意する。
8. 招待対象、配布日時、version、対応環境、同意日時、停止状態を内容非保持の台帳で追跡する。

未署名installerを「モニター版」として外部配布しない。実機試験用の内部成果物と招待配布物を混在させない。

## 4. モニター開始時の確認

利用者は開始前に次を1項目ずつ確認する。

- 18歳以上である。
- 実在人物、未成年、年齢不明、非同意・搾取表現を使用しない。
- 参照画像は架空の成人として端末内で確認済みである。
- 生成と保存は端末内で行い、MANGAI Cloudへ同期されない。
- 外部Providerを使用しない。
- Project保存先とバックアップ先を確認した。
- 生成内容を含まない技術情報だけを報告する。

確認が欠ける場合はProject作成または生成をfail closedで停止する。確認状態をUIだけで迂回できるものとして扱わず、Electron mainと生成policyで再評価する。

## 5. 段階公開

### Stage 0: 内部受入れ

- 署名済みPilot成果物をクリーンWindowsへinstallする。
- 4生成方式、キャンセル、失敗再実行、素材保存、Page配置、PDF、バックアップ／復元、uninstallを確認する。
- Promptや画像を含まない実機証跡だけを取り込む。

### Stage 1: 1名

- 1名へ個別招待し、導入と最初の1枚をスタッフ同席で確認する。
- 24時間以上観察し、データ消失、意図しない通信、起動不能、重大な安全境界違反がないことを確認する。

### Stage 2: 最大3名

- Stage 1合格後だけ追加する。
- 端末差、model導入、4生成方式、部分修正、書き出し、再起動復元を比較する。

### Stage 3: 最大5名

- Stage 2合格後だけ追加する。
- 7日以上の継続利用、生成成功率、平均再試行、書き出し成功、バックアップ復元、問い合わせ量を確認する。

段階を飛ばさず、各Stageの結果を責任者が確認してから次へ進む。

## 6. 収集する情報

収集可能:

- ランダムなモニターID
- アプリversion、Windows version、GPU種別、VRAM帯、RAM帯
- ComfyUI／Ollama／workflow version
- 操作種別、成功／失敗区分、所要時間、再試行回数
- 成果物のSHA-256、PDF page数、バックアップ／復元結果
- 秘密値を含まない分類済みerror code

収集禁止:

- 氏名、メール、端末名を実機証跡へ格納すること
- Prompt、Negative Prompt、参照画像、mask、生成画像、完成Page
- API key、token、署名鍵、ローカル絶対path
- 成人向け作品内容の自由記述を自動送信すること

利用者が作品内容を含む画面を共有する場合は、通常の自動報告とは分離し、共有範囲と削除方法を個別に確認する。

## 7. 停止条件

次のいずれかで新規招待と生成を停止する。

- 成人向けデータがCloudまたは外部Providerへ送信された疑い。
- 未成年、年齢不明、実在人物、非同意・搾取表現の拒否を迂回できる。
- Project、素材、Page、バックアップの回復不能な消失。
- 同一操作の重複実行、意図しない一括生成、無制限再試行。
- Prompt、画像、秘密値が診断または報告へ含まれる。
- installerまたは製品EXEの署名不正、checksum不一致。
- 起動不能、書き出し不能、または同一原因の重大障害が2端末以上で発生。

停止時は外部送信や自動削除で復旧せず、対象versionの配布を止め、既存Projectを保持したまま原因を調査する。

## 8. Pilot合格条件

- 招待者以外へ配布されていない。
- 全参加者が18歳以上確認と利用範囲に同意している。
- Cloud／外部Provider送信0件。
- 4生成方式を各参加者が最低1回完了できる。
- 生成画像を素材保存し、Pageへ配置し、再起動後も復元できる。
- PDFまたは画像を書き出せる。
- 少なくとも1回、バックアップから別Projectとして復元できる。
- データ消失、安全境界違反、秘密値・内容漏えいが0件。
- 重大障害0件、または修正版で再受入れ済み。

Pilot合格は12GB以上の限定環境に対する判断であり、一般公開、8GB対応、成人向けCloud、成人向け外部Providerを承認しない。

## 9. 現在の判定

`PLAN_READY / DISTRIBUTION_BLOCKED`

リポジトリ実装と実機証跡回収経路は完成している。招待公開の開始には、信頼されたコード署名、署名済みPilot version、12GB以上の内部実機受入れ、固定workflow／model一覧、招待・停止運用の責任者承認が必要である。

Production、Cloud、外部Provider、利用者Project、creditは本計画の作成では変更しない。
