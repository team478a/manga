# Creator基本導線 受入確認

## 対象

一般漫画向けCloud版の次の導線を確認する。

1. ログイン
2. プロフィール更新
3. 作品画像のアップロード
4. 非公開保存
5. 作品編集と画像差し替え
6. 公開
7. 公開作品一覧・作品詳細の表示

## 自動検証

実装変更後は次のコマンドがすべて成功すること。

```powershell
npm run typecheck
npm run lint
npm run hub:test
npm run build
```

## 本番実機テスト

テスト専用のクリエイターアカウントと、権利上問題のないJPG、PNGまたはWebP画像を使用する。

### 1. プロフィール

- `/login` からログインできる。
- `/dashboard` で表示名と自己紹介を保存できる。
- 空の表示名、81文字以上の表示名、1001文字以上の自己紹介が拒否される。
- 保存後にページを再読み込みしても入力内容が維持される。

### 2. 作品の非公開保存

- `/dashboard/works/new` で作品名、説明、画像、タグを入力する。
- 「非公開で保存」を選ぶ。
- 保存後、作品管理には表示される。
- `/works` の公開一覧には表示されない。
- 10MB超、拡張子偽装、壊れた画像が拒否される。
- タグの重複は1件に整理され、11件以上は拒否される。

### 3. 編集と画像差し替え

- 作品名、説明、タグを編集して保存できる。
- 新しい画像へ差し替えられる。
- 再読み込み後も新しい画像が表示される。
- Supabase Storageの同じ作品フォルダーに、差し替え前の画像が残っていない。

### 4. 公開

- 編集画面で「公開する」を選び保存する。
- `/works` に作品が表示される。
- 作品詳細でタイトル、説明、画像、タグが正しく表示される。
- ログアウト状態でも公開作品を閲覧できる。

## 現在の既知事項

`works` Storage bucketは公開設定である。非公開作品は公開一覧や作品詳細から参照されないが、画像URLを知っている第三者に対する厳密なアクセス遮断にはなっていない。厳密な非公開化は、非公開bucket、認可付き配信、短時間の署名URLへ移行して別途対応する。
