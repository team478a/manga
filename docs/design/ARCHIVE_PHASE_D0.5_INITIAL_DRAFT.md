**状態: 履歴用。現行の仕様ではない。**

この文書は、2026-07-26に`UI_REDESIGN_PLAN.md`内へ最初に書かれたPhase D0.5（Desktop Project一覧／制作ワークスペース／設定画面の3画面）のビジュアル仕様ドラフトをそのまま保存したものです。

同日、責任者から「既存デザインの微調整ではなく、最新のプロ向けAIクリエイティブツール（コンセプト名『MANGAI Creative Studio』）として再設計する」との指示があり、対象をAI画像生成画面を含む4画面へ拡張したうえで[`DESKTOP_CREATIVE_STUDIO_SPEC.md`](DESKTOP_CREATIVE_STUDIO_SPEC.md)として書き直されました。

**画面仕様の正本は`DESKTOP_CREATIVE_STUDIO_SPEC.md`です。以下は初回イテレーションの記録として残すのみで、実装の根拠として参照しないでください。**

## 旧・目的（当時の記述）

Phase D1以降でコードへ反映する前に、MANGAI Desktopの中核3画面（Project一覧／制作ワークスペース／設定画面）のビジュアル仕様を文書として確定する。本フェーズはコード変更を一切行わない。ワイヤーフレーム・仕様の承認を得てからPhase D1（トークン導入）へ進む。

## 旧・前提となる暫定方針（責任者指示、2026-07-26時点）

- Desktopを最優先する。Hubのデザイン実装はDesktopの基本デザイン確定後に行う。
- ダークテーマを維持する（`CURRENT_UI_AUDIT.md`で確認済みの`:root { color-scheme: dark; }`、`forced-colors`対応を継続）。
- 紫系アクセント（現行`--accent: #6848d8`系統）を維持する。
- Adobe系制作ツール（Photoshop/Clip Studio Paint等）が持つ専門性の高い密度の高いUIと、初心者でも迷わない分かりやすさを両立する。
- 画面構成は「左＝構成・素材」「中央＝Canvas」「右＝プロパティ・レイヤー・AI」の3カラムを維持する。
- 上部に現在地表示と主要操作、下部に保存・接続・生成状態を配置する。
- DesktopをTailwindへ移行しない。
- Hubのデザイン実装はDesktop確定後に着手する。
- DesktopとHubはコードを共有せず、トークン名・コンポーネントAPI設計のみを共通化する。

- **フォーム**（新規Projectモーダル）: `FormField`（label+input）。必須項目には視覚的な必須マーク、エラーはフィールド直下に赤系（`--danger`）で表示。
- **ステータス表示**: 自動バックアップ状態は`StatusBadge`の5トーン（neutral/info/success/warning/danger）を使用。「正常」は`success`、進行中は`info`、失敗は`danger`。

**狭幅時の左右パネル動作**: Home画面には左右パネルが存在しないため対象外（制作ワークスペースのみ該当）。

**長い作品名・空状態・エラー状態・生成中状態**

- 既存の`.skip-link`（`a11y.skipMain`）を維持し、`#main-content`へジャンプできること
- Project cardは`<article>`＋見出し要素の組み合わせとし、カード全体をクリック可能にする場合もキーボードから`Tab`＋`Enter`で到達・実行できること

- コントラスト比: 本文文字と背景で4.5:1以上、大きい文字（見出し等）で3:1以上（WCAG AA準拠）

**主操作と副操作の優先順位**

1. **主操作**: 各Providerの有効/無効切替、接続先設定の保存
2. **副操作**: 接続確認、診断の実行
3. **三次操作**: テンプレート管理、Runtime Profile詳細設定、監査履歴の閲覧

**初回利用者の制作フロー**

1. 初回は全Provider無効状態。設定画面を開くと「AIを使うにはOllamaまたはComfyUIを設定してください」という案内が最上部に表示される
2. 接続先URL入力→「接続確認」ボタンで即座にフィードバック
3. 診断機能は上級者向けの位置づけとして、初回フローでは強調しない

**コンポーネント仕様**

- **ボタン**: 「接続確認」「診断実行」は`Button variant="secondary"`、Provider有効切替はトグルスイッチ
- **カード**: 各Providerセクションは`Card variant="default"`へ統一
- **フォーム**: 接続設定フィールド群は`FormField`の標準密度を使用
- **ステータス表示**: 接続確認結果、診断結果はすべて`StatusBadge`5トーンに統一

**レスポンシブ配置**

| 解像度 | 配置 |
| --- | --- |
| 1920×1080 | タブ内コンテンツは最大幅を持たせ、中央に余白付きで配置 |
| 1366×768 | タブ内コンテンツはほぼフル幅使用、縦スクロールで全項目を閲覧 |

**狭幅時の左右パネル動作**: 設定画面は左右パネル（Asset/Inspector）を持たない。

**長い項目名・空状態・エラー状態・生成中状態**

- **長い項目名**: プルダウン/リスト表示で省略＋tooltip。
- **空状態**: モデル一覧が未取得の場合「モデル一覧を取得できませんでした。接続確認を行ってください」を表示。
- **エラー状態**: 接続失敗、保存失敗は該当フィールド直下にインラインエラー表示。
- **生成中状態**: 診断実行中は`aria-busy="true"`＋進捗表示。

**アクセシビリティ要件**

- タブは`Tabs.tsx`のARIA tablist実装をそのまま使用
- 各セクションの折りたたみには`aria-expanded`を付与
- Provider有効切替のトグルスイッチには明示的な`aria-checked`とlabelを付与
- `aria-busy`を診断・接続確認の非同期処理に一貫して使用
