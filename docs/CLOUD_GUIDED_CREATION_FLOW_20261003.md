# Cloud漫画制作の目的別ステップ化

## 背景

Productionの非公開2ページE2Eで、作品作成後の画面に原稿チェック、生成進捗、復旧、書き出し、販売準備が同時に並び、初めて使う利用者が「何があり、次に何をすればよいか」を判断しにくいことを確認した。E2Eを無理に継続せず、操作性改善を先に行う。

## 変更内容

- 作品画面の先頭に、現在の状態から次の目的を1件だけ案内する「目的別・制作ステップ」を追加した。
- 制作工程を「構成を作る」「原稿を仕上げる」「完成版を固定する」「完成原稿を出力する」「販売を準備する」の5段階に整理した。
- 全工程、原稿チェック、生成・復旧状況は必要時に展開する詳細領域へ移した。
- ページ編集画面は「コマ」「画像」「文字（任意）」「保存・確定」の順番と現在の次操作を表示する。
- creditを使うAI制作アシストは折りたたみ、既存画像で制作する基本操作と分離した。品質検査から修正候補を適用する場合は、自動的にAI領域を開いて従来の導線を維持する。

## 維持する条件

- ページ確定、完成版checkpoint、PDF、商品準備の既存条件は変更しない。
- 公開、販売開始、決済、Provider実行、credit予約・消費を自動実行しない。
- DB schema、migration、API契約、作品データを変更しない。
- Production E2Eで作成済みの非公開作品は保持し、改善のmerge・反映後に正規UIから再開する。
